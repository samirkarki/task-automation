# Royalty-Free Music Library

Place royalty-free MP3/WAV tracks here for use in long-form compilations.
The pipeline auto-picks the **first file found** (alphabetical order).

## Recommended Sources

- **YouTube Audio Library** (safest for monetised YouTube videos):
  - Go to YouTube Studio → Create → Audio Library
  - Filter: Genre = Electronic / Hip-Hop, Mood = Upbeat, License = Free to use
  - Download and place tracks here

- **Free Music Archive** – https://freemusicarchive.org (CC0 / CC-BY licensed)

- **Incompetech** – https://incompetech.com (CC-BY; credit in video description)

## Naming Convention

```
gaming_upbeat_01.mp3
gaming_chill_02.mp3
electronic_hype_03.wav
```
